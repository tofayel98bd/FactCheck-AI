FactCheck AI (ফ্যাক্টচেক এআই)
পূর্ণাঙ্গ প্রজেক্ট ডেভেলপমেন্ট গাইডলাইন ও রোডম্যাপ


ফেজ ১: প্রজেক্ট সেটআপ ও আর্কিটেকচার (সপ্তাহ ১)

• ভার্শন কন্ট্রোল: প্রজেক্টের জন্য একটি GitHub Repository খুলুন এবং টিমের সবাইকে যুক্ত করুন।

• টেক স্ট্যাক নির্ধারণ:
  ◦ Backend: Python (FastAPI) – এআই এবং ডেটা স্ক্র্যাপিংয়ের জন্য সবচেয়ে দ্রুত ও সেরা।
  ◦ Frontend: Next.js বা React.js (Vercel-এ হোস্টিংয়ের জন্য সহজ)।
  ◦ AI/LLM: Google Gemini API (Grounding ফিচার) অথবা LangChain + OpenAI API।
  ◦ Database: MongoDB (সাধারণ ডেটার জন্য) এবং ChromaDB বা Pinecone (ভেক্টর ডেটা ও RAG-এর জন্য)।


ফেজ ২: ব্যাকএন্ড ও এআই ইঞ্জিন তৈরি (সপ্তাহ ২)

• API Endpoints তৈরি: FastAPI দিয়ে একটি মেইন রুট (যেমন: /api/verify-fact) বানান, যা ইউজারের টেক্সট ইনপুট রিসিভ করবে।

• রিয়েল-টাইম সার্চ ইন্টিগ্রেশন: ইউজারের দাবির সত্যতা খুঁজতে Google Custom Search API বা Serper API যুক্ত করুন রিয়েল-টাইম ডেটার জন্য।

• RAG (Retrieval-Augmented Generation): সার্চ থেকে পাওয়া ডেটাগুলো LangChain-এর মাধ্যমে LLM-এ প্রম্পট হিসেবে পাঠান।

• Trust Scoring: প্রম্পটে নির্দেশ দিন যেন এআই পারসেন্টেজ (যেমন: সত্যতা ৮০%) এবং সাথে ৩টি সোর্স লিংক আউটপুট হিসেবে দেয়।


ফেজ ৩: টেলিগ্রাম বট ইন্টিগ্রেশন - MVP (সপ্তাহ ৩)

• বট তৈরি: টেলিগ্রামে 'BotFather' থেকে নতুন বট ক্রিয়েট করে API Token সংগ্রহ করুন।

• ব্যাকএন্ড কানেকশন: python-telegram-bot বা aiogram লাইব্রেরি দিয়ে FastAPI ব্যাকএন্ডের সাথে কানেক্ট করুন (Webhook)।

• রেসপন্স ফরম্যাটিং: টেলিগ্রামের মেসেজে মার্কডাউন ব্যবহার করে রেজাল্ট (যেমন: [মিথ্যা] ট্যাগ) এবং ক্লিকেবল সোর্স লিংক সুন্দরভাবে দেখান।


ফেজ ৪: ওয়েব অ্যাপ ফ্রন্টএন্ড তৈরি (সপ্তাহ ৪)

• ইউজার ইন্টারফেস (UI): সিম্পল ল্যান্ডিং পেজের মাঝখানে সার্চ বার এবং ইমেজ/স্ক্রিনশট আপলোডের অপশন রাখুন।

• রেজাল্ট পেজ (Result Card): মিটার বা প্রোগ্রেস বার, এআই-এর যৌক্তিক ব্যাখ্যা এবং রেফারেন্স লিংক দেখান।

• লাইভ গুজব রাডার: ওয়েবসাইটে "টপ ৫টি গুজব" লাইভে দেখার জন্য একটি বিশেষ সেকশন রাখুন।


ফেজ ৫: ডিপ্লয়মেন্ট ও টেস্টিং (সপ্তাহ ৫)

• হোস্টিং (Hosting): ফ্রন্টএন্ড Vercel বা Netlify-তে এবং ব্যাকএন্ড Render, Railway বা VPS-এ ডিপ্লয় করুন।

• টেস্টিং: টিমের সবাই মিলে ৫-১০টি ভুয়া খবর ইনপুট দিয়ে সোর্স ট্র্যাকিং এবং রেসপন্স টাইম (১-২ মিনিট) চেক করুন।


ফেজ ৬: হ্যাকাথন পিচ ও প্রেজেন্টেশন (সপ্তাহ ৬)

• স্লাইড ডেক: পিডিএফ বা পাওয়ারপয়েন্টে ৪-৫ পেজের পিচ ডেক বানান ('সমস্যা', 'সমাধান' ও 'মার্কেট ইমপ্যাক্ট' হাইলাইট করে)।

• লাইভ ডেমো প্রস্তুতি: স্টেজে দেখানোর জন্য আগে থেকেই ৩-৪টি ইন্টারেস্টিং নিউজ রেডি রাখুন যেন দ্রুত লাইভ টেস্ট করানো যায়।
